# Grey Zone Intel Memo — US-Iran vs Iran War 2026 Analysis

A politically neutral, multi-lens strategic analysis of the 2026 Iran war, styled as a Grey Zone
Intelligence & Analytics report. Built with a sense-making toolkit combining systems thinking,
Cynefin, and Wardley-style value-chain mapping — presented in the final report without naming the
underlying frameworks.

## Contents

- **`index.html`** — the full report. References images from `/assets` (not yet in this repo —
  see note below). Open directly in a browser once assets are added, or publish via GitHub Pages
  (Settings → Pages → deploy from `main` / root).
- **`us-israel.owm`, `iran.owm`** — Wardley Map source (OnlineWardleyMaps DSL). Paste into
  [onlinewardleymaps.com](https://onlinewardleymaps.com) to view/edit.
- **`cynefin-initial-scenario.mmd`, `cynefin-current-scenario.mmd`** — Mermaid `quadrantChart`
  source for the two Cynefin placement comparisons (28 Feb 2026 vs. mid-Aug 2026).
- **`kumu_elements.csv`, `kumu_connections.csv`, `kumu_loops.csv`, `kumu_loop_membership.csv`** —
  the systems loop diagram as a Kumu.io-importable dataset. Three loops modeled: Escalation Loop
  (R1, reinforcing), Exhaustion Loop (B1, balancing), and the emergent War Containment Loop (B2),
  which connects R1 and B1 and — as of 20 Aug 2026 — includes a "Political Override of Military
  Assessment" node representing a documented gap between internal military assessment and public
  political posture.

report's own Methodological Note and References sections for sourcing and confidence caveats.
